# ABAP Debugger Data View Extension

Extends the ABAP Debugger to display internal table and structure data as ABAP source code for use in tests.

For details, see these articles:

- [ABAP Debugger enhancement: test data creation](https://blogs.sap.com/2017/12/17/abap-debugger-enhancement-or-how-to-speed-up-your-test-data-creation-process/)
- [ABAP Debugger enhancement update](https://blogs.sap.com/2019/02/22/abap-debugger-enhancement-update/)

A [German description of this extension](https://www.objective-partner.de/abap-debugger-erweiterung/) is also available.

Repository documentation, comments, messages, and object descriptions are maintained in English. The abapGit master language is English (`E`). Technical identifiers and SAP API names retain their existing spelling.
